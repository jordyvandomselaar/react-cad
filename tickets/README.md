# v0 Tickets

Local implementation tickets for `@jordyvd/react-cad` v0.

## Status values

- `Todo` — not started.
- `In Progress` — actively being worked.
- `Blocked` — cannot continue without a decision or dependency.
- `Done` — accepted against the ticket criteria.

## Tracking

- Master status board: [`status.md`](./status.md)
- Keep each ticket frontmatter status in sync with `status.md`.
- When implementation starts, update one ticket to `In Progress`; avoid parallel unrelated work unless explicitly planned.
